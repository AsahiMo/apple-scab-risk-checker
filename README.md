# リンゴ黒星病 感染危険度チェック

アメダスの気温・降水量データから、リンゴの葉の濡れ時間を推定し、Millsテーブルに基づいて黒星病（Apple Scab）の感染危険度を判定するWebアプリです。無料枠のみで構成されています。

> **対象範囲**：ここで判定する感染危険度は、越冬した落葉上の子のう殻から放出される**子のう胞子による一次感染**の危険度です。園地内で発病した病斑上に形成される分生胞子による二次感染は対象に含みません。

## 構成

| コンポーネント | 内容 |
|---|---|
| `frontend/` | 静的サイト（住所検索・観測地点選択・濡れ時間推定・感染危険度判定・グラフ表示）。GitHub Pages等での配信を想定 |
| `src/index.js` | 気象庁のアメダス過去データ取得プロキシ（Cloudflare Workers） |
| `data/stations.json` | 観測地点マスタ（地点番号・地点名・観測要素・緯度経度・標高） |
| `scripts/build-obsdl-stations.mjs` | 地点マスタを生成するNode.jsスクリプト |

## amedas-proxy（Cloudflare Workers）

### デプロイ手順

```bash
npm install -g wrangler
wrangler login          # ブラウザでCloudflareアカウントにログイン（無料プランでOK）
wrangler deploy
```

ソースは `src/index.js`（`wrangler.toml` の `main` と一致させること）。

初回デプロイ時、Cloudflareアカウントに workers.dev サブドメインが未登録の場合は
Cloudflareダッシュボードの Workers 設定画面でサブドメインを登録してから、
もう一度 `wrangler deploy` を実行してください。発行される公開URLは
`wrangler deploy` の出力に表示されるものを使用してください（デプロイ前に決め打ちしないこと）。

### 動作確認

このAPIは気象庁の公式なAPIではない内部インターフェースを利用しているため（下記「制限事項」参照）、デプロイ後は必ず値の妥当性を確認してください。

```bash
curl "https://<デプロイ先のURL>/api/amedas?station=s47662&from=20260801&to=20260802"
```

- `temperature_c` が気温として妥当な範囲か（例: 8月の東京なら25〜35℃程度）
- `precipitation_mm` が降水量として妥当な範囲か（0〜数十mm程度）

エラーになる場合は `wrangler tail` でログを確認すると、取得できた生レスポンスの一部がエラーメッセージに含まれます。

### API仕様

```
GET /api/amedas?station=<stid>&from=YYYYMMDD&to=YYYYMMDD
```

| パラメータ | 説明 |
|---|---|
| `station` | 観測地点番号（`data/stations.json` のキーと同じ形式）。官署は `s` + 5桁（例: `s47662`＝東京）、AMeDAS専用地点は `a` + 4桁（例: `a0365`＝小河内） |
| `from` / `to` | 取得期間（YYYYMMDD形式、日本標準時） |

レスポンス:

```json
{
  "station": "s47662",
  "from": "20260801",
  "to": "20260802",
  "hourly": [
    { "datetime": "2026-07-31T16:00:00.000Z", "temperature_c": 27.0, "precipitation_mm": 0 }
  ]
}
```

## 地点マスタ（`data/stations.json`）

```
{
  "generatedAt": "...",
  "source": "...",
  "count": 1678,
  "stations": {
    "<stid>": { "name": "地点名", "prid": "都道府県コード", "kansoku": "観測要素フラグ", "lat": 0, "lon": 0, "alt": 0 }
  }
}
```

- `kansoku` は6桁の観測要素フラグ文字列。桁の意味は左から `[降水量, 風, 気温, 日照時間, 積雪・降雪, その他]`。値は `'0'`=観測なし、`'1'`=観測あり、`'2'`=一部期間のみの限定観測。気温・降水量が両方使える地点かどうかは `kansoku[0] !== '0' && kansoku[2] !== '0'` で判定する。
- `lat` / `lon` は10進度（南半球の地点は負値）、`alt` は標高(m)。

再生成するには:

```bash
node scripts/build-obsdl-stations.mjs
```

`frontend/` 配下は依存ライブラリなしの静的サイトです。ローカルで確認する場合は任意のHTTPサーバーで配信してください。


### 濡れ時間推定ロジック

長野県の試験成績に基づく以下のルールで、アメダスの時別データから葉の濡れ時間帯を推定します。

- 降水があると濡れが開始する
- 降水終了後2時間まで濡れが継続する
- 降水終了後2時間以内に再度降水があった場合、濡れは継続する
- 夜間（20:00〜7:00）は、降水が終了しても7:00まで濡れが継続する

疑似コード:

```
夜間 = 20:00〜翌6:59（7:00は夜間に含めない）

last_rain_hour = なし
for 各時刻 h（時系列順、1時間刻み）:
    if 降水量[h] > 0:
        wet[h] = True
        last_rain_hour = h
    else:
        if last_rain_hour が設定されている:
            経過時間 = h - last_rain_hour
            if 経過時間 <= 2:
                wet[h] = True
            elif h が夜間:
                wet[h] = True
            else:
                wet[h] = False
                last_rain_hour = なし
        else:
            wet[h] = False
```

※日中に一度完全に乾いた（`last_rain_hour` がリセットされた）場合、夜になっても再度濡れ扱いにはならない。

### 感染危険度判定（Millsテーブル、子のう胞子による一次感染）

濡れ期間ごとの平均気温 `t`（℃、小数点第一位で四捨五入）と連続濡れ時間から、以下の3本の閾値曲線（4次多項式）で判定します。

| 判定 | 表示ラベル | 濡れ時間の閾値（時間） |
|---|---|---|
| S | 警報 | `2.0510e-3t⁴ - 1.3758e-1t³ + 3.4430t² - 3.8804e1t + 1.8879e2` |
| M | 危険 | `1.2775e-3t⁴ - 8.6231e-2t³ + 2.1779t² - 2.4841e1t + 1.2271e2` |
| L | 注意 | `9.8032e-4t⁴ - 6.6561e-2t³ + 1.6916t² - 1.9339e1t + 9.4446e1` |

実際の連続濡れ時間が閾値以上であれば、その判定（S→M→Lの順に厳しい方から判定）となります。いずれの閾値も満たさない場合は「**感染リスク低**」と表示します（局地的な微気象等により感染の可能性が皆無とは言い切れないため、「リスクなし」ではなく低リスクという表現にしています）。また、平均気温が5℃未満または25℃を超える場合はMillsテーブルの適用範囲外のため「**判定不能**」と表示し、判定を行いません。判定結果は表とグラフ（横軸: 期間平均気温、縦軸: 連続濡れ時間）の両方で表示されます。

### 感染危険度判定（褐斑病、子のう胞子による一次感染）

りんご褐斑病（*Diplocarpon mali*）の子のう胞子による一次感染は、以下の単純な閾値モデルで判定します（`frontend/app.js`の`classifyKappanbyo()`）。

- 葉面濡れ時間が **6時間以上**
- 濡れ期間中の平均気温が **13.8℃以上**

両方を満たす濡れ期間は「**感染成立**」、それ以外は「**-**」と表示します。黒星病の判定（Millsテーブル、5〜25℃の範囲に限定）とは独立した基準のため、黒星病が「判定不能」となる気温域（25℃超など）でも褐斑病側は成立と判定されることがあります。結果テーブルに黒星病の判定列と並べて表示されます。

## 制限事項

- amedasのデータ取得は気象庁の「過去の気象データ・ダウンロード」ページが内部で使用しているインターフェースを利用しており、公式に仕様が公開されているAPIではありません。ページの実装変更により動作しなくなる可能性があります。
- 直近1日分のデータはまだ確定していないことが多く、取得できるのは前日分までです。
- 1回のリクエストで取得できる期間には上限があります（1地点・気温+降水量の2項目・時別値の場合で約900日＝2.5年程度）。
- 観測開始時期・観測頻度は地点により異なります。古くからある官署でも時別データが揃うのは比較的最近（数十年前）からで、それ以前は3時間おきなど粗い観測しかない期間があります。AMeDAS専用地点はその地点の設置年以降のみ利用できます。
- アメダスの観測地点は必ずしも果樹園内にあるわけではなく、局地的な結露・霜などの微気象は反映されません。あくまで参考指標です。
- 感染危険度の判定期間は、黒星病の感染期が春〜夏中心であることを踏まえ、同一年内のみ指定できる仕様にしています。
